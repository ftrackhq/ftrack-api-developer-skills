# ftrack Skills

Agent skills for ftrack development workflows.

## What's included

| Skill | Description |
|-------|-------------|
| [ftrack-create-pull-request](skills/ftrack-create-pull-request/SKILL.md) | Create GitHub PRs with the org template and linked Linear tickets |

## Prerequisites

- `gh` CLI authenticated with access to the ftrackhq GitHub org
- Linear MCP server connected
- Git repo with a feature branch checked out

## Install

```bash
npx skills add ftrackhq/skills
```

## Update

```bash
npx skills update ftrackhq/skills
```
